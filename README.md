# Home Rental Management System (Web-Based Edition)

## Project Overview

A web-based Home Rental Management System designed to provide a role-based, multi-user platform for managing rental properties, tenant bookings, payments, and related rental activities.

The system is developed using core, framework-free web technologies to strengthen fundamental web development skills.

## Technology Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Core PHP
- **Database:** MySQL
- **Communication:** Standard HTTP requests and native PHP form handling
- **Architecture:** Role-based, multi-user web application
- **Frameworks:** No external frontend or backend frameworks

## User Roles

The system supports four types of users:

1. **Super Admin**
2. **Admin**
3. **Property Owner**
4. **Tenant**

## Core Features

### Common Features

- User registration
- Login and logout
- Password change/reset
- Profile management
- Personalized dashboard

### Super Admin

- Manage Admin, Property Owner, and Tenant accounts
- Configure system-wide settings
- Monitor transactions and payment activity
- View platform-wide analytics
- Access audit and activity logs

### Admin

- Approve or reject property listings
- Review and resolve complaints
- Suspend accounts violating platform policies
- Moderate reviews and messages
- Generate activity reports

### Property Owner

- Create, update, and remove property listings
- Upload multiple property photos
- Manage property details and amenities
- Approve or reject tenant booking requests
- Communicate with tenants
- Track rent payments and payment history

### Tenant

- Browse and search available properties
- Filter properties by city, price, and amenities
- View property details, photos, pricing, and availability
- Submit booking requests
- Track booking status
- Make rent payments through supported payment methods
- Communicate with property owners
